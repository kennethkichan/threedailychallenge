# **App Name**: Formulaic

## Core Features:

- Daily Challenge: Daily Challenge Generation: Use an AI tool to generate a set of 3 unique logic challenges daily, focusing on pattern recognition, shortcut mathematical calculations, and mixed reasoning. The AI will choose from a diverse range of topics and difficulty levels suitable for high school students.
- Problem Display: Problem Presentation: Display each challenge with its problem statement and four answer choices in a clear and engaging format.
- Answer Selection: Answer Input: Provide an interface for the user to select their answer for each problem.
- Solution Explanation: Solution Display: Display the correct answer and a concise explanation of the solution, including any shortcuts used.
- Streak Counter: Progress Tracking: Track the user's daily streak of correct answers to motivate them.

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082), evokes intellect, focus, and a sense of the academic.
- Background color: Very light lavender (#F0F8FF), creates a soft, calming backdrop to maintain readability.
- Accent color: Saturated Gold (#FFD700), draws attention to key interactive elements like the submit button and correct answers, while supporting the theme of knowledge.
- Body and headline font: 'Inter', a sans-serif font known for its clarity and modern design.
- Use simple, geometric icons to represent different problem categories.
- Ensure a clean, uncluttered layout with ample whitespace to avoid cognitive overload.
- Use subtle animations (e.g., a gentle fade-in) when displaying solutions to provide positive feedback.
